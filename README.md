# Company Management System - MVC

A demo **ASP.NET Core MVC** project built for learning and practicing **MVC architecture, Separation of Concerns, and N-Layer Architecture**.

## 📌 Project Overview

This project was built as a hands-on application to practice end-to-end web development using ASP.NET Core MVC. It focuses on cleanly separating responsibilities between the data access, business logic, and presentation layers, while building interactive UI components.

## 🎯 Project Goal

The main goal of this project is to practice and understand:

* ASP.NET Core MVC
* MVC request and response flow
* N-Layer Architecture & Separation of Concerns (SoC)
* Repository Pattern
* Entity Framework Core
* Full CRUD Operations with Entity Relationships
* Model Binding & Server-Side / Client-Side Validation
* Dependency Injection
* Interactive Razor Views, Tag Helpers, and Partial Views


## 🛠️ Technologies & Tools

* **Backend**: C#, ASP.NET Core MVC, Entity Framework Core, LINQ
* **Frontend**: Razor Views, HTML5, CSS3, Bootstrap, jQuery Validation
* **Database**: SQL Server
* **Architecture & Patterns**: N-Layer Architecture, Repository Pattern, Dependency Injection
* **Tools**: Visual Studio, Git & GitHub
